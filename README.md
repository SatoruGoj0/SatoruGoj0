## 🧭 About me

- 🐧 Porting **Debian 13 (trixie)** to ARM64 laptops — I maintain [**DebianOnDragon**](https://github.com/SatoruGoj0/DebianOnDragon), a live + installer ISO for the Lenovo IdeaPad Slim 3 with a **Snapdragon X X1-26-100**, built around a **mainline kernel** and a custom **devicetree** derived from the board's own ACPI tables.
- ⚙️ At home in the low-level trenches: kernel configs, ACPI → DTS extraction, firmware wrangling, GRUB boot flows.
- 💻 Building apps in **TypeScript** — desktop tools, web apps, and the occasional experiment.
- 🤖 Letting **GitHub Actions** do the heavy lifting — ISOs build and publish themselves on every push.
